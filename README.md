# Buddy App (site)

Public hosting for the **Buddy App** static site. It's served with GitHub Pages at
https://williamc64.github.io/buddy-app-site/

This repo contains only the built site files: plain HTML, CSS and JS with no build step. It includes a web app
manifest (`manifest.webmanifest`), a service worker (`sw.js`) and icons, so the site installs as a PWA and can be
packaged with PWABuilder. Development happens in a separate private repository; files here are published copies.
